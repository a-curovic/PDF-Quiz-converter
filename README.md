A full-stack web application that converts uploaded PDF documents into automatically generated quizzes, combining PHP-based user management with a Python NLP/ML backend for question and answer generation.

What This Project Does

* Users upload a PDF document

* The system extracts and cleans text

* NLP and transformer models generate quiz questions with explanatory answers

* Quizzes are displayed through a clean web interface

* User authentication and admin controls are handled via PHP

Backend (ML / NLP)

* Python

* PyPDF2, spaCy

* Hugging Face Transformers (T5, BERT)

* TF-IDF for content ranking

Web / Backend

* PHP (authentication, routing, admin panel)

* MySQL (user storage)

* Session-based login system

Frontend

* HTML / PHP templates

* CSS (style2.css)

* JavaScript (script.js)
